# slide-storyboard v0.1.0

## 初回公開

アジェンダから全スライドのドラフトを作成し、利用者が流れを確認・修正してから、単一の HTML ストーリーボードにまとめるエージェントスキルです。

## 含まれるもの

- スライドごとの内容、レイアウト、図表仕様、素材、出典、未確認事項をまとめる手順
- レイアウト済みの HTML テンプレートとレイアウト候補プレビュー
- README、コントリビューション・行動規範・セキュリティ方針
- Issue / Pull Request テンプレートと再実行可能な検証

## インストール

```bash
npx skills add KotaSugiki/slide-storyboard --skill slide-storyboard --agent codex
```

Claude Code の場合は `--agent codex` を `--agent claude-code` に置き換えてください。
